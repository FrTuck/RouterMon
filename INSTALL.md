# Установка RouterMon

RouterMon ставится на роутеры с OpenWrt. ПК нужен только один раз — чтобы поставить его на первый (основной) роутер;
остальные роутеры установщик находит сам или их можно добавить потом со страницы.

## 1. Что понадобится

- Роутер с OpenWrt, к которому подключён ПК, и **пароль root** этого роутера (тот же, что для входа в LuCI).
  Если пароль никогда не задавался — задайте его в LuCI: «Система → Администрирование».
- На роутере включён SSH (в OpenWrt по умолчанию включён: «Система → Администрирование → Доступ по SSH»).
- ПК в той же локальной сети:

| ПК | Что нужно |
|---|---|
| Windows 10 (1803+) / 11 | ничего: встроенные PowerShell, `ssh` и `tar`. Если `ssh` нет — «Параметры → Приложения → Дополнительные компоненты → Клиент OpenSSH» |
| Linux | `ssh`, `tar`, `curl` или `wget` (обычно уже есть) |
| macOS | ничего: всё встроено |

## 2. Скачать

- Кнопка **Code → Download ZIP** на странице репозитория, затем распаковать архив в любую папку, **или**
- `git clone https://github.com/FrTuck/RouterMon.git`

## 3. Установить на основной роутер

**Windows:** двойной щелчок по `install.cmd`.
**Linux / macOS:** в терминале в папке RouterMon: `sh install.sh`

Дальше установщик:

1. Спрашивает **IP основного роутера** и сразу подставляет шлюз вашего ПК — обычно это он и есть, достаточно нажать Enter.
2. Подключается по SSH и **спрашивает пароль root** (если в `~/.ssh` нет подходящего ключа). Пароль вводится в ssh,
   установщик его не видит и не сохраняет.
3. Ставит RouterMon: файлы, служба сбора, веб-сервер на порту 8089. Занимает 10–20 секунд.
4. **Ищет в сети другие роутеры с OpenWrt** без RouterMon и, если находит, предлагает поставить и на них
   (для каждого спросит его пароль root).
5. Пишет адрес страницы: `http://<IP роутера>:8089/`. Первые графики появятся через 20–30 секунд.

## 4. Добавить роутеры позже

На странице в шапке — **«+ Добавить роутер ▾»**:

- **Найдены в сети, без RouterMon** — роутеры OpenWrt, которые видит основной роутер. Щелчок открывает мастер.
- **Новый роутер по IP** — ввести адрес вручную и нажать «Проверить».

Мастер проверяет адрес, показывает, какие доступы нужны и зачем, и после вашего согласия ставит RouterMon по SSH
с основного роутера. Пароль root нового роутера при этом идёт от браузера к роутеру по HTTP без шифрования —
пользуйтесь мастером в доверенной сети или ставьте с ПК: `install.cmd` / `sh install.sh <IP>`.

Роутеры, на которых RouterMon уже стоит, появляются на главной сами (поиск раз в минуту).

## Установка из консоли и параметры

```
.\install.ps1                                   # Windows: спросит IP (по умолчанию — шлюз ПК)
.\install.ps1 -Hosts 192.168.1.1                # конкретный роутер
.\install.ps1 -Hosts 192.168.1.1,192.168.1.2    # несколько сразу
.\install.ps1 -Hosts 192.168.1.1 -NoScan        # без поиска других роутеров
.\install.ps1 -Hosts 192.168.1.1 -Key ~\.ssh\my_router_key

sh install.sh                                   # Linux / macOS
sh install.sh 192.168.1.1 192.168.1.2
RMON_NOSCAN=1 RMON_KEY=~/.ssh/my_router_key sh install.sh 192.168.1.1
```

Вход: сначала пробуются ключи `~/.ssh/id_*` (или указанный), иначе ssh спрашивает пароль.

## Установка без ПК (прямо на роутере)

Если у роутера есть доступ в интернет, можно поставить и с самого роутера (по SSH, например через PuTTY):

```
cd /tmp
uclient-fetch -O rmon.tar.gz https://github.com/FrTuck/RouterMon/archive/refs/heads/main.tar.gz
tar -xzf rmon.tar.gz
sh RouterMon-main/web/lib/setup.sh install 8089
rm -rf rmon.tar.gz RouterMon-main
```

## Обновление

Скачайте новую версию и запустите установщик так же, указав все роутеры (или ответив «да» на найденные):
`.\install.ps1 -Hosts 192.168.1.1,192.168.1.2`. Накопленная история и списки роутеров сохраняются.

## Удаление

```
.\install.ps1 -Hosts 192.168.1.1 -Uninstall     # Windows
sh install.sh --uninstall 192.168.1.1           # Linux / macOS
sh /etc/rmon-web/lib/setup.sh remove            # на самом роутере
```

Удаляются файлы, служба, экземпляр веб-сервера, записи в `/etc/sysupgrade.conf`; журнал DNS (если включался) выключается.

## Если не получилось

| Сообщение | Что сделать |
|---|---|
| `Permission denied` | неверный пароль root или вход по паролю запрещён: LuCI → «Система → Администрирование → Доступ по SSH» |
| `Connection refused` / `timed out` | неверный IP или SSH выключен; проверьте, что LuCI открывается по этому адресу |
| `это не OpenWrt` | RouterMon работает только на OpenWrt |
| `нет веб-сервера uhttpd` | `opkg update && opkg install uhttpd` (или `apk add uhttpd` на OpenWrt 25+) |
| `порт 8089 уже занят` | `.\install.ps1 -Hosts <IP> -Port 8090` |
| `осталось N КБ флеш-памяти` | освободите место на роутере (нужно ~400 КБ) |
| Windows: «выполнение сценариев отключено» | запускайте `install.cmd`, а не `install.ps1` |
